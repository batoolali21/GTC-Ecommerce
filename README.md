# 🚬 GTC — Golden Tobacco Company | Premium Catalog Website

A sleek, dark-themed **multi-page product showcase** for a premium tobacco & smoking accessories brand — built with pure **HTML, CSS & JavaScript** (no frameworks). Features dynamic product rendering, live category filtering, and instant **WhatsApp-based ordering** for a true e-commerce feel without needing a backend.

---

## ✨ Features

- 🏠 **Elegant Homepage** — full-cover hero section, brand story, and featured products
- 🗂️ **Dynamic Product Catalog** — 24 products rendered live from a single JS data file (no hardcoded HTML)
- 🔍 **Category Filtering** — Cigarettes, Fine Cut Tobacco, Hookah Flavors, Cigars & Cigarillos, Accessories
- 📄 **Product Detail Pages** — auto-generated per product via URL parameters (`?id=`)
- 💬 **One-Click WhatsApp Ordering** — auto-generates a pre-filled order message with product name & price
- 📍 **Google Maps Integration** — direct turn-by-turn directions to the store location
- 📱 **Fully Responsive** — clean grid-based layout adapts to mobile, tablet & desktop
- 🎨 **Luxury Dark & Gold Theme** — consistent branding across all pages

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure |
| CSS3 | Styling & responsive layout (`STYLE2.css`) |
| Vanilla JavaScript | Dynamic rendering, filtering, WhatsApp link generation |

No build tools, no dependencies — just clone and open in a browser.
